# Auto Battler — relic that plays your battles for you. Like Whispering Earring, but EVERY TURN.

### *Configurable* Automation
1. Auto Play Cards — automatically plays every card in hand, similar to Whispering Earring.
2. Auto End Turn — once no playable cards remain, your turn ends on its own (requires Auto Play Cards).
3. Auto Use Potions — automatically drinks one or several potions at the start of each turn (skips Foul Potion and Ashwater).

### *Configurable* Bonuses
1. Bonus Energy — adds 0–10 extra Energy at the start of each turn.
2. Bonus Draw — adds 0–10 extra draw at the start of each turn.

Every value is adjustable in the mod settings, so you can build anything from a small power boost (enabling only bonuses, and turning off automation) to a full auto-battler run that plays battles without your intervention.

All settings can be changed mid-run safely.

## Multiplayer support

Works in co-op — restrict which players receive the relic with a SteamID64 filter, or leave it blank to give it to everyone in the lobby. (Heads up: all players should sync their settings, not just the host.)

## Run start toggle

Choose whether every new run starts with the relic automatically, so you can turn the relic on/off between runs without disabling the mod.
